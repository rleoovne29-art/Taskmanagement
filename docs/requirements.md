# 要件定義書 - Trello風タスク管理アプリ

## 1. 背景・目的
- 個人学習用に、Trelloのような「カードを列（ステータス）ごとに管理する」タスク管理アプリを作る。
- 未経験者がWeb開発の基礎（HTML/CSS/JavaScript、ブラウザストレージ）を学びながら完成させることを目的とする。

## 2. 想定利用者
- 開発者本人（自分専用のタスク管理ツールとして使う）
- 同じブラウザ・同じPCで利用する前提（他人とのデータ共有は想定しない）

## 3. スコープ（今回作る範囲）

### 3.1 含む機能（MVP）
| # | 機能 | 内容 |
|---|------|------|
| 1 | 列の表示 | 「To Do」「Doing」「Done」の3列を画面に表示する |
| 2 | カード追加 | 任意の列にタスク名（テキスト）を入力してカードを追加できる |
| 3 | カード削除 | 不要になったカードを削除できる |
| 4 | カード移動 | カードを別の列に移動できる（ドラッグ&ドロップ、またはボタン操作） |
| 5 | データ保存 | ブラウザを閉じて再度開いても、カードの内容と配置が保持される（localStorage使用） |
| 6 | カード編集 | カードのタスク名を後から書き換えられる |
| 7 | 期限日 | カードに期限日（日付）を設定・表示できる |
| 8 | 優先度 | カードに優先度（高・中・低）を設定し、色分けして表示する |

### 3.2 含まない機能（今回は対象外）
- ユーザー登録・ログイン機能
- 複数ボードの作成・切り替え
- 担当者・ラベルなどのカード詳細情報
- サーバー・データベースを使ったデータの保存（他端末との同期）
- 複数人での共同編集

## 4. 非機能要件
- 特別な環境構築なしで、ブラウザで`index.html`を開くだけで動作すること
- スマホ対応は必須としない（PCのブラウザで動作すればよい）

## 5. 使用技術
- HTML / CSS / JavaScript（フレームワーク不使用）
- データ保存: ブラウザの`localStorage`

## 6. 画面イメージ（ラフ）
```
┌────────────────┬────────────────┬────────────────┐
│     To Do      │     Doing      │     Done       │
├────────────────┼────────────────┼────────────────┤
│ [+ カード追加]  │ [+ カード追加]  │ [+ カード追加]  │
│ ┌────────────┐ │ ┌────────────┐ │                │
│ │ タスクA     │ │ │ タスクB     │ │                │
│ │ 優先度: 高  │ │ │ 優先度: 中  │ │                │
│ │ 期限: 7/25  │ │ │ 期限: 7/28  │ │                │
│ │[編集][削除][→]│ │[編集][削除][→]│ │                │
│ └────────────┘ │ └────────────┘ │                │
└────────────────┴────────────────┴────────────────┘
```

## 7. カードが持つ情報（データ項目）
| 項目 | 内容 | 例 |
|------|------|----|
| タスク名 | カードのタイトル | 「資料を作成する」 |
| 列（ステータス） | To Do / Doing / Done のいずれか | Doing |
| 期限日 | 任意項目。設定しなくてもよい | 2026-07-25 |
| 優先度 | 高・中・低の3段階（デフォルトは「中」） | 高 |

## 8. 今後の拡張候補（MVP完成後に検討）
- ラベル・タグ機能
- 複数ボード対応
- スマホ対応（レスポンシブデザイン）
- 期限超過カードの強調表示（例: 赤枠にする）
